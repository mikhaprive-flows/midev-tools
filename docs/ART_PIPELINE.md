# Art Pipeline (code-generated pixel art)

No paint program is installed; **all art is generated by Python recipes** → reproducible, reviewable, diffable.
Toolkit: `tools/art/pixelkit.py` (Pillow + resvg). CLI: `python midev.py`.

```bash
python midev.py list                # recipes in art_src/recipes
python midev.py new torch           # scaffold art_src/recipes/torch.py from _template.py
python midev.py build torch         # build one (then auto-validate)
python midev.py build               # build all
python midev.py validate            # palette / alpha / sheet-size checks
python midev.py watch               # live file watcher (hot-reload on save)
```

## Style rules (classic 32-bit)
- Palette: `tools/art/palettes/fisharium32.hex` (31 named colors). Every pixel is snapped to it; `validate` fails otherwise.
  Refer to colors by **name** (`"skin"`, `"gold"`, `"outline"`). Add colors only by appending to the file (board note).
- Alpha is binary (0/255). No anti-aliasing; outlines 1 px via `Canvas.outline()` (dark `outline` color).
- Sizes: tiles 16×16; player/NPC frames 32×32 (feet at y=28); items/chests 16×16; backgrounds e.g. 400×224 layers.
- Light comes from top-left: highlights top-left, `*_dark`/`shadow` bottom-right. Use `Canvas.dither()` for gradients.
- Animation fps guide: idle 3–4, walk 8–10 (6 frames), run 12–14, dash 16–20 (non-loop), interact 12–14 (non-loop).

## Two drawing styles (mix freely)
**Raster** (`Canvas`, best for characters & tiles):
```python
from pixelkit import Canvas, SheetBuilder, bob, swing
c = Canvas(32, 32)
c.rect(10, 10, 12, 8, "teal").circle(16, 8, 5, "skin").px(14, 8, "outline").dither(0,0,32,4,"night")
c.outline()            # selective dark outline
frame = c.done()       # palette-snapped PIL image
```
**Vector** (SVG → resvg, best for geometric props, UI, backgrounds):
```python
from pixelkit import svg_frame, svg_doc, hexc
img = svg_frame(svg_doc(16, 16, f'<rect x="2" y="4" width="12" height="9" fill="{hexc("wood")}"/>'), 16, 16)
```
Use integer coordinates and `viewBox` = pixel size; `shape-rendering=crispEdges` is forced. See `recipes/chest.py`.

Motion helpers: `swing(i, n, amp)` signed limb offset, `bob(i, n, amp)` vertical bounce. See `recipes/player.py`
(parametric `figure()` function; animations are just parameter sweeps — extend this pattern for new actions).

## Output & metadata format (contract with `core/assets/SpriteSheet`)
`SheetBuilder(name, fw, fh, origin)` → `game/assets/sprites/<name>.png` (one row per animation) + `<name>.json`:
```json
{"name":"player","frameWidth":32,"frameHeight":32,"originX":16,"originY":28,
 "animations":{"walk_down":{"row":1,"frames":6,"fps":10,"loop":true}}}
```
Output dirs from `ctx`: `ctx.sprites`, `ctx.tiles`, `ctx.ui`, `ctx.backgrounds`, previews → `ctx.preview`.
Terrain atlas `tiles/terrain.png`: column index == `Tile.id` (order in `recipes/terrain.py` must match the enum).

## Self-review loop (mandatory)
1. `tools\art.ps1 build <recipe>`
2. `read_file build\art_preview\<name>_<anim>.gif` / `*_contact.png` (4× scaled) — check silhouette, readability, motion.
3. `tools\dev.ps1 shot <name> --debug` to see it in-game at real scale.
4. Iterate on the recipe. Keep frame size constant within a sheet.
